## Active Harness: cc-sample-harness

### Coding Standards
- Follow the project's existing conventions before introducing new patterns
- Prefer explicit over implicit
- Write code that reads like prose — clear names, clear intent

### Git Workflow
- Commit messages follow conventional commits format: `feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`
- Always run tests before committing
- Keep commits atomic — one logical change per commit
